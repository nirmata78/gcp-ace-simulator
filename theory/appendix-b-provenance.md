# Appendix B — Provenance and limits
{: .no_toc }

1. TOC
{:toc}

- **Built from** the official *Associate Cloud Engineer Certification exam guide* live from **30 June 2026**
  (Google's standard exam-guide PDF, retrieved 27 September 2026), the exam facts on Google's certification page,
  and Google Cloud product documentation. The earlier edition of this booklet (2 September 2026) supplied much of
  the stable product material; it was written against the previous five-section guide.
- **The simulator's question bank follows the same guide**: every question is tagged with the guide objective and
  bullet it tests, so a miss points back to the section of this booklet that Appendix A names.
- **Recently renamed or introduced products** — Gemini Enterprise Agent Platform (formerly Vertex AI), Agent
  Runtime, Antigravity CLI (Gemini CLI's successor), Cloud Hub, Database Center, Managed Lustre — are described at
  the level the guide asks for. Their consoles and commands move quickly; check the product page before relying on
  a detail.
- **Volatile facts are marked *verify*** rather than stated: prices, discounts, quota defaults, machine catalogues,
  retention windows of recently changed features.
- **Commands show the shape of a call.** Names, regions and IDs are placeholders. Every `gcloud` command was
  checked on 29 September 2026 against the Google Cloud SDK's own command surface (SDK 572): the release track
  (`beta` / `alpha` where the command has no GA version) and, for GA commands, every flag used.
- **Examples are original**, written for this booklet; they are not taken from the exam. The practice scenarios that
  used to close each part are in [Practice scenarios](practice-scenarios.md).
- **About 70% is the community convention for the pass mark.** Google does not publish a cut score.
- **Not affiliated with, endorsed by, or sponsored by Google LLC.** Independent study material.
