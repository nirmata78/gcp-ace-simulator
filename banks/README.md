# Question banks

The simulator ships **without questions**. A question bank is a folder, and git ignores every folder here:

```
banks/
  private/            the default bank: git ignores it, and no image contains it
    sections/         one JSON file per exam-guide section, the source of truth
    register.json     generated by `kb.py reindex`; never edit it
    retired.json      removed ids, which are never reused
    reviews/          the ledgers of /expand and /rework runs (they quote questions, so they stay here)
  <any-other>/        a bank of your own, used with ACE_BANK_DIR
```

## Connecting a bank

| Where | How |
|---|---|
| From source | Put the bank in `banks/private/`, or start with `ACE_BANK_DIR=/path/to/bank streamlit run app.py` |
| `kb.py` | Uses the same bank: `ACE_BANK_DIR=/path/to/bank python scripts/kb.py check` |
| Docker | `compose.yaml` mounts `./banks/private` read-only. Use `ACE_BANK_HOST=/path/to/bank docker compose up` for another folder |

A bank's questions follow the schema in the [README](../README.md#adding-questions) and the
[question standard](../docs/question-standard.md). Run `python scripts/kb.py check` and `python scripts/kb.py lint` on
it before using it.

## Starting an empty bank

```bash
mkdir -p banks/private/sections
echo '{"retired": []}' > banks/private/retired.json
python scripts/kb.py add --file my-first-question.json   # validates, mints the id, writes the section file
```

## Tests

The tests never read your bank. They generate a fixture bank of placeholder questions (`tests/fixture_bank.py`). To
run them on a real bank, set `ACE_TEST_BANK_DIR=banks/private pytest -q`.
